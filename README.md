# UIU Section Planner

Plan your UIU (UCAM) course sections: pick a section, day pattern and time, and instantly see conflicts and gaps.

- Theory: Sat+Tue or Sun+Wed, 6 slots (08:30–16:30)
- Lab: single day (Sat/Sun/Tue/Wed), 2.5h slots (08:30–11:00, 11:11–13:40, 14:00–16:30)
- Live conflict check while choosing a time, weekly timetable, per-day gaps
- Edit / remove a course to swap sections quickly
- Data is saved in your browser (localStorage)

## Run locally
Open `index.html` in a browser (no build step).

## Deploy
Push to GitHub → import the repo in Vercel → Framework preset: **Other** → Deploy.
